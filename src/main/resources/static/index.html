Method

Numbers first. Verdict second.

GambitRate is an opinionated read of the games you have already played. It looks for a result pattern, then asks whether the sample is strong enough to say it matters.

How a verdict is assigned

Each opening group is compared with your overall win rate for that color. A verdict needs at least five games and a two-sided 95% z-test. Groups below the minimum game count are hidden.

What rating cost means

The signed cost is an estimate: (color baseline win rate − group win rate) × games × 10. Positive values suggest rating cost; negative values suggest rating gain. It is a ranking aid, not a chess.com rating receipt.

What this page does not claim

PGN clocks show time, not move quality. A low clock is not a blunder. Without an engine, this page does not claim to know which move caused a loss. Accuracy is only shown by the API when chess.com supplied it.
